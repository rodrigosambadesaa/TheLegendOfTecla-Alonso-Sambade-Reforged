# Entrega original Alonso Castro / Sambade Saa

Código fuente recuperado del archivo de entrega
`Alonso_Castro_Miguel_Sambade_Saa_Rodrigo Entrega3.zip`.

La propia fuente atribuye las clases centrales a Rodrigo Sambade Saá y Miguel
Alonso Castro. Esta versión obtuvo un 6/10. Se conserva sin binarios ni
configuración privada del IDE; únicamente se ha aplicado un formateador para
que el histórico sea legible. La reconstrucción moderna se añade en commits
posteriores y no altera este punto de partida.
